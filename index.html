LectorVoz Pro · Guía de Publicación y Uso

Cómo subir a GitHub Pages y configurar tu publicidad

1. ¿Cómo publicar en GitHub Pages?

Esta aplicación web está diseñada para ser 100% estática:

  1. Sube los archivos de este directorio a tu repositorio de GitHub (ejemplo: git add ., git commit -m "Web app", git push).
  2. En tu repositorio en GitHub, dirígete a Settings → Pages.
  3. En Branch, selecciona main (o master) y la carpeta / (root).
  4. Haz clic en Save. ¡En 1 minuto tu aplicación estará disponible online en una dirección gratuita https://tu-usuario.github.io/tu-repo/!

2. ¿Cómo configurar Google AdSense o Anuncios?

En el archivo index.html encontrarás tres bloques etiquetados claramente:
• #ad-slot-top (Banner superior)
• #ad-slot-sidebar (Banner lateral 300x250)
• #ad-slot-bottom (Banner inferior)
Simplemente reemplaza el bloque de ejemplo con la etiqueta <ins class="adsbygoogle" ...> que te proporcione Google AdSense.

3. Atajos de Teclado

  • Barra Espaciadora: Reproducir / Pausar
  • Esc: Detener reproducción
  • Flecha Derecha: Siguiente oración
  • Flecha Izquierda: Oración anterior

Esta herramienta opera de manera estrictamente local en el navegador de tu computadora o teléfono celular.
