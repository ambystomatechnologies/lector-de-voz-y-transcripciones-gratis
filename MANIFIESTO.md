# MANIFIESTO DE INSTRUCCIONES DEL PROYECTO
# Ambystoma Technologies - Lector de voz & transcripciones

## Regla de Oro: Sin Pruebas Automáticas no Solicitadas

- **Prohibido realizar pruebas automáticas por cuenta propia**: No usar herramientas de navegador (como subagentes de navegador), ni scripts de comprobación demorados, a menos que el usuario lo solicite explícitamente en el prompt.
- **Validación del usuario**: El usuario es quien realiza las pruebas, comprobaciones y validaciones de cada funcionalidad.
- **Enfoque de trabajo**: Aplicar los cambios directamente, con precisión técnica y entregar inmediatamente el resultado al usuario para no hacerle perder tiempo.
